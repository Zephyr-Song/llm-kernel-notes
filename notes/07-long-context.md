# 07 · 长上下文：架构、位置编码与外推

> 整理中。核心内容散落在 04-rope.md 和 05-mha-gqa-mqa.md，这里做统一索引和补充。

## 三个独立的瓶颈

长上下文不是「单一难题」，而是三个互不相关的瓶颈同时出现：

| 瓶颈 | 表现 | 解决手段 |
|---|---|---|
| **位置编码外推** | 模型在训练长度外崩溃 | RoPE 插值（YaRN）、继续训练 |
| **Attention 复杂度** | O(N²) 计算与显存 | FlashAttention、稀疏注意力 |
| **KV cache 爆炸** | 显存装不下 | GQA/MQA/MLA、KV 量化、滑窗 |

**很多人把这三个混为一谈。** 搞清楚是哪个先撞墙，才知道该优化什么。

**典型的撞墙顺序**：模型训练时最长 4K → 微调扩到 32K（位置编码OK）→ 发现 KV cache 占满显存（GQA 不够）→ 最后才需要考虑 attention 效率。

---

## 位置编码外推

详见 [04-rope.md](04-rope.md)。核心结论速记：

- **崩溃主因是 PIT**（注意力分布偏移），不是「位置编码没定义」
- **没有零成本方案**：所有生产级长上下文模型都做了继续训练
- 现代方案：YaRN（分段+温度修正）或 LongRoPE（渐进式扩展）

## Attention 效率

详见 [03-attention-from-scratch.md](03-attention-from-scratch.md)。

| 方法 | 思路 | 代表 |
|---|---|---|
| **FlashAttention** | IO-aware，显存 O(N²)→O(N) | FA-2 |
| 稀疏注意力 | 只attend 选定的位置 | Longformer, BigBird |
| 滑动窗口 | 只 attend 最近 W 个 | Mistral, Gemma-2 |
| 线性注意力 | 用核方法近似 softmax | Linformer, Performer |
| SSM | 彻底不用 attention | Mamba |
| MLA | 压缩 KV，不是稀疏注意力 | DeepSeek-V2 |

## KV cache 压缩

详见 [05-mha-gqa-mqa.md](05-mha-gqa-mqa.md)。优先级：

```
GQA (模型自带) → PagedAttention (框架) → FP8 量化 → 分组量化 → MLA (架构期定死)
```

## 各家模型的长上下文方案对照

| 模型 | 上下文 | 方案 | 要点 |
|---|---|---|---|
| GPT-4 | 128K | 未公开 | 闭源，只能观察行为 |
| LLaMA-3.1 | 128K | base=500000 + 渐进式扩展 + 8K→128K 继续训练 | 不做推理时插值 |
| Qwen2.5 | 128K (部分 1M) | YaRN + 分段 | 配置项 `rope_scaling` |
| DeepSeek-V2 | 128K | MLA + YaRN | KV 压缩 + 位置插值 |
| Mistral | 32K/128K | 滑动窗口 | KV 与长度解耦 |
| Kimi | 200K | 未完全公开 | 推测用了长上下文专门训练 |

**通用规律**：**没有模型是靠「改个参数」白嫖长上下文的。** 都会经历「短上下文预训练 → 中等长度扩展 → 长上下文继续训练」的阶段。

## 评测长上下文的陷阱（对你的研究也有用）

如果你在 SafeBARS 或任何评测工作里用到长上下文模型，注意几点：

1. **「宣称长度」≠「有效长度」**。模型标称 128K，但在 60K 之后的检索准确率可能已经接近随机。要做**长度分桶评测**（如 8K/16K/32K/64K 分别测）。

2. **位置偏好**。RoPE 模型常有 U 形的位置效应——开头和结尾的信息更容易被用到，中间容易被忽略。用「大海捞针」（Needle in a Haystack）测试时要控制针的位置分布。

3. **「大海捞针」过于简单**。它只测单条精确检索，不能反映长上下文的真实困难。真实困难是：
   - **多跳推理**（需要综合分散在长文中的多条信息）
   - **长程依赖**（两个相隔很远的句子有逻辑关系）
   - **干扰抵抗**（长上下文里有大量相似但无关的信息）

4. **KV 压缩的副作用**。用了 GQA/MLA/量化的模型，在长上下文下的检索能力下降幅度通常**显著大于**短上下文。这也是「宣称长度」和「有效长度」差距的来源之一。

> 如果你的研究涉及「LLM 在长上下文中的行为」，第 4 点是个很有说服力的观察角度 —— 可以作为 related work 或讨论部分的切入点。
